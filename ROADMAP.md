# Roadmap

- Sprint 0: Complete — Windows foundation and read-only diagnostics (`v0.1.0-alpha.1`).
- Sprint 1: Complete and accepted — production-grade mesh diagnostics, evidence selection, bounded Deep checks, performance evidence, and schema 2.0 (`0.2.0-alpha.1`).
- Sprint 2: Complete and accepted by automated gates — protected workspace repair, evidence-bound plans, eight controlled operations, checkpoints, undo/restore, accept/rollback, comparison, and repair audit schema 1.0 (`0.3.0-alpha.1`). Installed-panel and real-statue UAT remain deferred.
- Sprint 2.5: Complete — dataset `1.0.0` with 27 rights-cleared, hash-validated real statue meshes.
- Sprint 2.6: Complete — permanent Golden Benchmark Baseline for all 27 meshes, including production analysis/repair/audit outputs, comparisons, timings, CPU/memory evidence, statistics, schema fingerprints, hashes, manifest, verifier, and future-release regression runner. Operator-reviewed real-statue repair UAT remains deferred.
- Sprint 2.8: Specification complete for review — research-backed Printability Engineering Specification, profile/report schemas, validation fixtures, source ledger, and Sprint 3 acceptance gates. No runtime implementation; Sprint 3 remains unstarted.
- Sprint 3: Not started — printability validation and print-oriented export.
- Sprint 4: Controlled remeshing.
- Sprint 5: Chroma3D internal UAT.
- Sprint 6: Reference and asset workflows.
- Later phases: bounded AI-assisted planning and authoring workflows.
- Later commercial work: packaging, licensing, support, and distribution design.

The roadmap does not promise fully autonomous museum-quality sculpting or guaranteed print success.

Sprint 2.7 storage architecture is implemented on the review branch: external release-asset packaging, deterministic archive verification, independent locks/versioning, offline fetch tooling, and current-HEAD payload externalization. External repository publication remains pending review; Sprint 3 remains unstarted.

Sprint 2.8 is the implementation-contract milestone. Review and approve
[PRINTABILITY_SPECIFICATION.md](PRINTABILITY_SPECIFICATION.md) before authorizing
Sprint 3 runtime work.
