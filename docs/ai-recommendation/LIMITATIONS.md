# Limitations

- The OpenAI adapter is implemented, but a live development or production provider call is not proven by local fake/mock tests. Provider availability, model behavior, retention, latency, quotas, and cost may change.
- Standard-library synchronous HTTPS is explicit and bounded; Blender's synchronous operator model means cancellation is best-effort at phase boundaries rather than guaranteed remote request termination.
- No provider response is a geometry, cultural/iconographic, printability, material, manufacturing, slicer, or physical-print authority. No global optimum or guaranteed outcome is claimed.
- The feature consumes current Sprint 5/6 evidence; missing, stale, skipped, failed, budget-exhausted or indeterminate evidence remains visible and may block action.
- Model configuration is explicit. No support matrix, billing, account, backend, telemetry, learning, prompt history, cache reuse, vision/reference-image input, or procedural sculpt generation is included.
- Manual installed-panel UAT, Blender 4.5 LTS, slicer comparison, material calibration and physical printing require separate evidence.
