# Preview and Approval

Recommendation generation and selection are read-only. An actionable recommendation resolves only an existing current Sprint 5 candidate/plan or Sprint 6 strategy. Preview displays that deterministic target through the established workflow and does not authorize execution.

Approval is a separate explicit action bound to source, context, policy, provider/model, recommendation and preview hashes. A source/workspace/context/policy/profile/settings/provider/model/schema/prompt/candidate/strategy/implementation/file-state change revokes it. Execution delegates to Sprint 5/6 checkpointed operations; the AI layer contains no geometry mutation.

Failure restores the existing workspace start boundary when possible and records the result. Acceptance requires current comparison evidence and creates a separate copy; it never replaces/deletes the source. Reject/discard touches only session-owned resources.
