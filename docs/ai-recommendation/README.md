# AI Recommendation Foundation

Sprint 7 adds optional advisory recommendations over current deterministic Sprint 5/6 evidence. It does not analyze raw geometry with an AI model, generate geometry, or control Blender. The local core remains fully available without a key or network.

Workflow: complete and rank Intelligent Optimization -> enable the collapsed AI Recommendation panel -> enter a bounded goal -> prepare and inspect context -> consent -> make one explicit request or choose offline fallback -> review a locally validated recommendation -> select -> preview -> approve that exact preview -> delegate to Sprint 5/6 -> compare -> accept a separate copy or discard -> export redacted evidence.
