# Controlled Optimization

Sprint 5 is a bounded software-preview workflow above Safe Repair, Printability, and Advanced Preparation.

1. Select a protected mesh and start a session.
2. Generate deterministic candidates and a read-only plan.
3. Apply one reviewed step at a time to the isolated workspace.
4. Review comparison and fidelity evidence; undo or restore when needed.
5. Accept a separate optimized copy or discard the session workspace.
6. Export the JSON or Markdown audit.

The feature does not automatically optimize, replace the source, generate supports, hollow/resin-drain models, slice, generate G-code, control a printer, or guarantee print success. Physical printing, slicer comparison, material calibration, Blender 4.5 LTS, and installed-panel UAT are separate evidence tasks.
