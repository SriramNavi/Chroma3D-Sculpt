# G1 Recommendation

Status: `NOT_STARTED`.

Proceed only after owner-authorized CGB backend execution. The immediate G1 architecture should:

1. preserve the G0 provider-neutral request/job/artifact contract;
2. require explicit provider, model, projected jobs/cost, and user consent;
3. save raw provider output and identity before import or conditioning;
4. create a new Blender object rather than replace any protected source;
5. expose raw and conditioned evidence separately;
6. delegate repair/optimization to existing isolated workspaces, checkpoints, rollback, and accept-copy flows;
7. keep credentials environment/session-only and all network activity user-initiated;
8. provide offline/no-provider behavior without weakening current product functionality.

No commercial MVP backend or open foundation is recommended yet because no real CGB model run has occurred.
