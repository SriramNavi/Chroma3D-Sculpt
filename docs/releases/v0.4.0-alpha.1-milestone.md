# Chroma3D Sculpt v0.4.0-alpha.1 Milestone

## Release summary

`v0.4.0-alpha.1` advances Chroma3D Sculpt from the Dataset, Golden Benchmark, and storage foundations in `v0.3.1-alpha.1` to a profile-driven Printability Engine. It also includes the Sprint 3.5 framework for controlled future physical validation. The framework is prepared, but no physical print run or slicer comparison has been completed.

## Product capabilities

- Local, versioned Generic FDM, Generic Resin, Bambu Lab X1 Carbon, Bambu Lab P1S, and Prusa MK4 profiles, plus validated Custom profiles.
- Immutable world-space geometry facts feeding sampled wall-thickness, thin-feature risk, overhang, floating-component, build-plate contact, build-volume, and scale checks.
- Deterministic virtual orientation recommendations and conservative weighted risk scoring with explicit confidence, bounded evidence, and limit states.
- Stale-result protection, bounded evidence selection, schema 1.0.0 JSON and Markdown reports, and a native Blender Printability panel.

## Architecture

The advisory analysis flow is:

`Profile and settings` → `geometry facts` → `focused checks` → `risk aggregation` → `orientation recommendations` → `evidence and reports` → `Blender UI`

Profiles and settings establish the process constraints. Immutable geometry facts are shared by focused checks, whose explicit results feed conservative scoring and bounded virtual orientation candidates. The same evidence is presented through reports and the Blender panel.

## Safety model

- Analysis is read-only and does not mutate mesh geometry or object transforms.
- Results are advisory and do not guarantee printability or manufacturing success.
- Geometry, topology, winding, transform, profile, or settings changes invalidate stale evidence.
- No automatic scaling, orientation application, support generation, slicing, G-code generation, printer control, or runtime network access is performed.

## Known limitations

- Wall thickness is sampled and estimated, not an exact global minimum.
- Thin-feature analysis is a conservative connected-shell proxy and does not recognize local features merged into a larger shell.
- Build-plate contact stability is a geometric heuristic, not an adhesion or dynamics simulation.
- Orientation search is bounded and is not globally optimal.
- The extension does not generate supports, slice models, emit G-code, or apply scale or orientation changes.
- Physical FDM and resin calibration are pending, and no printability guarantee is provided.

## Upgrade significance

This release is a major alpha capability milestone because it integrates profile-aware printability risk analysis, evidence-backed recommendations, reporting, and a governed physical-validation framework into the existing diagnostics and repair product. It remains non-production advisory software: its bounded heuristics have not been physically calibrated and do not guarantee successful prints.
