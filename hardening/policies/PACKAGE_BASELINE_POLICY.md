# Package Baseline Policy

The H0 archive filename, byte size, member set, SHA-256, manifest identity, schemas, profiles, source modules, and forbidden-file result are the H1-H9 comparison anchor. Later package changes require an exact member diff, repository validator, Blender-native extension validation, registration lifecycle, and installed-package smoke where release scope requires it.

No secret, environment file, bytecode, tests, development scripts, nested repository root, or unapproved external runtime dependency may enter the archive. Version changes require a separately authorized release milestone.
