# Performance Comparison Policy

Performance claims require the same checkpoint-derived fixture, actual input size/triangle count, operation, mode, Blender version, and machine context. Compare multiple runs using minimum, median, and maximum where inexpensive. Correctness, source immutability, evidence truth, and cleanup gates run before accepting a speedup.

Point working-set before/after is not peak memory. OS, filesystem, and cache noise must be disclosed. Do not weaken safety limits, omit slow cases, or convert skipped/indeterminate work into pass to improve a number.
