# Printability Profile Examples

These JSON files are examples for schema and policy validation. They are not
calibrated print recipes. All thresholds are profile values with an explicit
classification and remain editable unless the schema says otherwise.

- `generic_fdm.json` and `generic_resin.json` use project defaults.
- `bambu_x1_carbon.json`, `bambu_p1s.json`, and `prusa_mk4.json` use
  manufacturer-sourced build-volume/hardware facts but project-default process
  thresholds.
- `custom_profile.template.json` requires user-owned values and sources.
